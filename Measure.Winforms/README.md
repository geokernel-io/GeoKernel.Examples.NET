# Measure.Winforms

Measure demonstrates how to add distance and area measurement tools to a GeoKernel Windows Forms viewer.

## Overview

It prepares the required sample data, loads world boundaries and city point layers, adds a scale bar for spatial reference, and provides toolbar actions for pan, distance measurement, area measurement, clear, and full extent.

## GIS Workflow

- Initialize a map viewer
- Download and load vector data
- Add interactive distance and area measurement tools
- Clear measurements and return to full extent

## Run

```powershell
dotnet run --project Measure.Winforms.csproj
```
